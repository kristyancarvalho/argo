## Fixed

- Real receive-path shaping through cgroup v2, conntrack, nftables ingress redirect, IFB, and `tc`.
- Durable QoS recovery, enforced adaptive ceilings, and correct interface lifecycle.
- Representation-safe resume and hardened partial-file handling.
- Crash-safe cross-filesystem publication and startup reconciliation.
- Daemon instance locking, NetworkManager recovery, and metered admission.
- Paginated history, wrapped-line watch redraw, and resilient TUI refresh and confirmation state.

## Security

- Concurrent bounded IPC now authenticates Unix peers and validates socket directories.
- URL secrets are redacted and untrusted terminal strings are sanitized.
- Absolute XDG validation prevents runtime state from resolving against a working directory.
