## Added

- A static Astro and TypeScript website built with npm for Vercel Git deployments.
- A custom institutional homepage with the Argo network-flow visual, current CLI examples, architecture, and project status.
- A branded Starlight documentation portal with substantive getting-started, download, configuration, networking, architecture, development, and troubleshooting guides.
- Release-backed changelog pages, canonical metadata support, social metadata, robots policy, and a branded 404 route.
- A dedicated GitHub Actions workflow for Astro checks, linting, formatting, and static builds.
- Static-output validation for generated routes, assets, fragments, and exclusion of internal development material.

## Changed

- Institutional pages now use full-width sections instead of a global application-style frame.
- The homepage uses a compact control-plane rail, consistent local SVG icons, wider visual canvases, and restrained flow animations with reduced-motion support.
- README and social-preview banners use portable outlined editorial typography aligned with the homepage display face.

## Fixed

- Centered the protected Unix IPC connector between the CLI/TUI and daemon architecture nodes.
- Restored a consistently light Starlight content surface in light mode while preserving the dark theme.
- Collapsed the empty Pagefind dialog while retaining bounded, scrollable search results on desktop and mobile.
