## Added

- `argo help`, `argo --help`, and `argo -h` output.
- Terminal-aware command color with `NO_COLOR` support.
- A Makefile target that builds and runs the daemon for local testing.

## Changed

- QoS policy state became observable through status and testable behavior rather than command generation alone.
- Terminal and policy behavior received focused release stabilization.
