## Added

- NetworkManager D-Bus observation for connectivity, active connection, interface, type, and metered state.
- Explicit automatic pause and resume behavior for metered connections.
- Strict TOML configuration loaded from the XDG configuration path.
- Runtime profile switching for rate, scheduler defaults, metered behavior, and active profile persistence.
- Network and profile state in typed IPC and `argo status`.
