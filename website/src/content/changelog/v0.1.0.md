## Added

- Persistent HTTP and HTTPS downloads owned by `argod`.
- SQLite state, crash recovery, and Unix-socket IPC.
- Add, list, show, pause, resume, cancel, and status commands.
- Single-stream rate limiting and the first unit, integration, end-to-end, race, lint, and build coverage.
