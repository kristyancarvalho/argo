title: Argo documentation

---

Argo is a Linux-first download manager built around a persistent, unprivileged daemon. The `argo` client and TUI control work over a protected Unix socket; closing either interface does not stop active transfers.

Argo also has an optional traffic-governance path. Scheduler priority orders downloads managed by Argo. System traffic policy is a separate control that determines how Argo traffic competes with other applications through an isolated privileged helper.

:::caution[Pre-1.0 software]
Argo is functional early-stage software. Commands and persisted data are covered by migrations and tests, but the compatibility surface is not yet declared stable. Review release notes before upgrading.
:::
